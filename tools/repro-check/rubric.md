# Rubric: is this reproduction package ready to post?

## Checks

| Check              | Evidence                                                                                 | Pass condition                                                                                                                                                                                                                                                                                                                                                          | Weight    |
| ------------------ | ---------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------- |
| Env-recorded       | The environment section of the reproduction report                                       | OS and tool version are both named. If the reporter's version differs from the one the issue was filed against, the difference is called out rather than silently substituted. If the issue specifes reproducing on the latest release, reproducing on a different version fails.                                                                                       | required  |
| Steps-recorded     | The steps section of the reproduction report                                             | Steps are present, ordered, and contain no gaps a reader would need to ask the author to fill                                                                                                                                                                                                                                                                           | required  |
| Issue-match        | The artifact(s) in the report read against the issue's described behavior                | The artifact shows the exact behavior the issue describes, not an adjacent or related error. Exception: if the outcome claim is "cannot reproduce" and Honest-outcome passes, Issue-match passes automatically since no failure artifact would match in this case.                                                                                                      | required  |
| Honest-outcome     | The outcome claim in the report and any attached attempt evidence                        | If not reproduced: evidence of the attempt is present. If reproduced: passes automatically while Issue-match handles target correctness                                                                                                                                                                                                                                 | required  |
| Artifacts          | Attached files in the report (error output, logs, screenshots, video)                    | At least one artifact that constitutes proof of reproduction is present                                                                                                                                                                                                                                                                                                 | required  |
| Claim-intent       | The candidate claim comment                                                              | The claim is specific to the issue and free of generic boilerplate, self-assignment demands, or guaranteed fix timelines.                                                                                                                                                                                                                                               | required  |
| Repo-conventions   | The submission compared to the repo's bug report template and contribution / AI policies | The report follows standard reproduction conventions (environment, steps, artifacts, outcomes). If the repo's contribution policy explicitly mandates AI disclosure on comments/issues, disclosure is present. Permissive AI policies, human-voiced comments on repos that restrict bot spam, or omitting non-essential template fields (like full package lists) pass. | required  |
| Actual-vs-expected | The written text of the report, independent of any artifact                              | The report explicitly states the observed behavior and the expected behavior as separate written claims                                                                                                                                                                                                                                                                 | preferred |

## Verdict rule

Accept if every required check passes; preferred checks never change the verdict; unclear counts as fail.
